Security, by design.

  • Never collect or store bank passwords, PINs or card security codes.
  • Use Stripe-hosted checkout and hosted payout onboarding.
  • Keep secret API keys and TOTP seed on the server in environment secrets.
  • Use an authenticator app for time-based one-time codes; standard TOTP changes every 30 seconds, not 47 minutes.
  • No system is “unhackable.” Use MFA, least privilege, rate limits, logging, updates, backups and independent security testing.
  • This starter is not production-ready: add a database, authenticated organiser accounts, CSRF protection, idempotent webhooks, inventory locks, refund flows, ticket issuance and monitoring.
